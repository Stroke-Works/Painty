# Painty 0.3.0

### What's New

**Editable projects** — Open and save drawings as `.painty` files.

**Canvas navigation** — Zoom with the mouse wheel and pan by dragging with the middle mouse button.

**Drawing tools** — Draw lines, rectangles and ellipses, with an optional fill.

**Colors** — Pick colors from the canvas and save a customizable palette.

**Release notes** — Click the version in Settings to read the notes for the installed version. Update prompts also show notes for the available version.
