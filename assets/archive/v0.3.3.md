# Painty 0.3.3

### What's New

**Floating window controls** — The title bar is gone; minimize, maximize and close now sit in a small rounded panel over the canvas.

**Full-window canvas** — The drawing area fills the entire window, including the strip behind the floating controls.

**Release channels** — Stable updates are published as Latest and betas as Pre-release, so each channel only offers the right builds.

### Installation

Download `PaintySetup-0.3.3.exe` for a new installation.

Already have Painty installed? Update directly from **Settings → Check for updates**, or install the update when prompted at startup.
