# Painty 0.3.2-beta.1

> Version bêta : disponible uniquement pour les utilisateurs qui ont activé le canal **Bêta** dans les réglages.

### What's New

**Custom title bar** — The window now uses Painty's own title bar, with minimize, maximize and close buttons.

**Beta channel** — Choose **Settings → Update channel → Beta** to also receive pre-releases.

**Smoother strokes** — Brush strokes follow the pointer without lag, with clean corners and sharper edges.

**Drawing tools** — Lines, rectangles and ellipses keep clean outlines at any zoom.

**Editable projects** — Saving and reopening `.painty` files is unchanged and fully compatible.

### Installation

Download `PaintySetup-0.3.2-beta.1.exe` for a new installation.

Already have Painty installed? Update directly from **Settings → Check for updates** (with the Beta channel enabled), or install the update when prompted at startup.
