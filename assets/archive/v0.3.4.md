# Painty 0.3.4

### What's New

**Cleaner window controls** — The floating panel is now more compact, with a drag grip, a thin separator and softer rounded hover highlights.

**Sharper icons** — Minimize, maximize and close use thinner, crisper strokes.

### Installation

Download `PaintySetup-0.3.4.exe` for a new installation.

Already have Painty installed? Update directly from **Settings → Check for updates**, or install the update when prompted at startup.
