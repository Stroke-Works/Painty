# 🎨 Painty 0.3.2-beta.1

> ⚠️ Version bêta : canal **Bêta** uniquement (Réglages → Canal de mise à jour).

### What's New

- 📁 Improved stability when saving and reopening `.painty` files.
- 🔎 Smoother zooming and panning for more precise editing.
- ✏️ Refined line, rectangle, and ellipse behavior for cleaner strokes.
- 📝 Updated release notes and version prompts for the current release.

### 📦 Installation

Download `PaintySetup-0.3.2-beta.1.exe` for a new installation.

Already have Painty installed? Update directly from **Settings → Check for updates**, or install the update when prompted at startup.
