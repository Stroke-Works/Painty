# 🎨 Painty 0.2.2

### What's New

- ✏️ **Smarter Eraser** — The eraser now cuts strokes exactly where it passes, even when you move fast. No more leftover fragments.
- 📤 **Reliable Export** — Large drawings export without errors, and very big images are scaled down automatically instead of failing.
- 🔄 **Safer Updates** — Each update is verified against a published checksum before it replaces the program.
- ⚙️ **Update Option** — Turn off the automatic check for updates at startup from **Settings**.
- ⚡ **Smaller and Faster** — The program is optimized and its icon is lighter, so the download is smaller.

### 🛠️ Fixes

- Undo history no longer loses its redo steps when clicking on empty space with the eraser.
- Version comparison now handles numbers correctly (e.g. 0.10.0 is newer than 0.9.0) and pre-releases.
- Language strings are checked for consistency between English and French.

### 📦 Installation

Download `PaintySetup-0.2.2.exe` for a new installation.

Already have Painty installed? Update directly from **Settings → Check for updates**, or install the update when prompted at startup.

> **Note :** versions 0.2.1 and earlier do not verify checksums. Updating from them is safe, but the verification only starts from 0.2.2 onward.
